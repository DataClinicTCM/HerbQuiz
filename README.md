# HerbQuiz
HerbQuiz – A Fun and Educational WeChat Mini Program for Learning Chinese Medicinal Herbs.

在中医药学习过程中，发现"看图识药"是最基础也是最重要的环节，但市面上缺乏简洁高效的认药训练工具，于是萌生了开发这款小程序的想法。
一款免费使用的微信小程序，通过随机展示中药高清图片，用户点击图片查看答案，帮助用户快速掌握中药形态特征，提升认药能力。
